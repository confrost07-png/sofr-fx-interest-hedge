# MODULE04 MINI PROJECT 03 · 2조

**은행 기업금융 RM의 달러대출 상담: 복리 SOFR·환율이 원화 이자부담에 미친 기여**

달러 변동금리 대출 차주의 원화 이자부담이 변할 때, 그 변화가 금리(SOFR) 때문인지 환율 때문인지 나눠 설명하는 가상 분석입니다.
미국 단기금리와 원/달러 환율의 시계열·상관관계를 분석하고, 표준 30일 원화 이자액의 변화를 금리 기여와 환율 기여로 나눕니다. 발표 뒤에는 상관 결과가 다른 방법에서도 버티는지 강건성 점검(유의확률, 신뢰구간, 다중비교 보정, 회귀)을 추가했습니다.

- 분석 기간: 2020-01 ~ 2025-12 (월별, 시작점은 2019년 12월 말 공통 관측일)
- 가상 차주: 원금 USD 1,000,000 · 고정 가산금리 연 2%p · 헤지 없음
- 조원: 원승연(조장·앱·강건성 점검) · 김동민(데이터) · 조윤호(보고서) · 정지수(발표) · 조진영(헤지 시나리오 분석)
- 제출본 버전: README v7 · 발표자료 v13 · 발표대본 v5 · **발표영상 v1 · 시연영상 v1 · API 명세서 v1** · metrics.json v1.2 · robustness.json v1.0 (2026-10-10)
- 영상으로 먼저 보려면: `video/미니프로젝트03_발표영상_v1.mp4` (AI 음성 발표 16분 4초, 13:03부터 앱 시연), 시연만 보려면 `video/미니프로젝트03_시연영상_v1.mp4` (1분 57초). 자세한 안내는 10절

## 4. 계산식

- 기간 복리 SOFR(연율) = (SOFR Index 말 ÷ SOFR Index 초 - 1) × 360 ÷ 실제 경과일수
- 환율 변화율 = ln(기간 말 원/달러 ÷ 이전 기간 말 원/달러)
- 표준 30일 원화 이자 C = 원금 × (복리 SOFR + 가산금리) ÷ 12 × 월말 환율
- 월간 C 변화 = 금리 기여 + 환율 기여 (교차항을 절반씩 나누는 대칭분해, 71개월 모두 오차 0.000000002원 이하)
- 상관계수 = 피어슨 r. 95% 신뢰구간은 피셔 z 변환, 유의확률은 t검정 (앱과 `robustness_check.py` 동일)

## 7. 해석 한계

- 표준 30일 이자액은 기간 길이를 맞춘 비교용 지표로, 실제 계약의 금리 재설정일·일수 계산·원금 상환·헤지를 반영하지 않습니다.
- DEXKOUS는 뉴욕 정오 기준 환율이라 국내 은행 매매기준율과 다를 수 있습니다.
- 수준값 상관은 두 변수 모두 추세가 있어 p값이 과장되고, 분석 기간을 바꾸면 부호까지 달라질 수 있습니다 (2023~2025년 -0.56). 그래서 참고값으로만 씁니다.
- 한국 금리·VIX·달러지수까지는 통제해 봤지만, 무역수지·외국인 자금 흐름 같은 다른 변수는 통제하지 않았습니다. 달러지수에는 원화가 일부 들어 있어 약간의 기계적 상관이 있습니다.
- 회귀·상관은 함께 움직이는 정도이지 인과가 아닙니다. 인과를 말하려면 FOMC 서프라이즈 이벤트 스터디 같은 설계가 필요합니다.

## 10. 발표·시연 영상 (`video/`)

| 파일 | 길이 | 내용 |
| --- | --- | --- |
| `미니프로젝트03_발표영상_v1.mp4` | 16분 4초 | 발표자료 v13 23쪽 + AI 음성 내레이션. **22쪽(12:53) 뒤 13:03~15:00에 앱 시연이 이어서 나오고**, 15:00부터 23쪽 결론 |
| `미니프로젝트03_시연영상_v1.mp4` | 1분 57초 | 앱 시연만 따로 |
| `*.srt` | - | 한국어 자막. 영상 안에도 끄고 켤 수 있는 자막 트랙으로 들어 있음 |
| `영상_내레이션_원고_v1.md` | - | 내레이션 전문, 쪽별 시작 시각, 사용한 음성 |

- **보는 방법**: 파일을 더블클릭하면 기본 플레이어(윈도우 미디어 플레이어·영화 및 TV, 맥 QuickTime)로 재생됩니다. 1920x1080, H.264/AAC라 코덱을 따로 설치할 필요가 없습니다.
- **자막 켜기**: QuickTime은 `보기 → 자막 → 한국어`, VLC는 `자막 → 하위 트랙`. 자막이 안 보이면 같은 이름의 `.srt`를 영상과 같은 폴더에 두고 열면 자동으로 붙습니다.
- **시연 순서** (1-5절 발표 시연 순서와 같음): 첫 화면 카드(+0.80, -0.05, 44/71, 972/800만원) → 기간을 2023-01 ~ 2025-12로 바꿔 수준값 -0.56 확인 → 상관분석 탭의 표본 수·p값·95% 신뢰구간과 수준값 주의 문구 → 전체 기간으로 되돌림 → RM 상담 탭에서 2022-11 선택(이자 +30만원, 금리 요인 +79만원, 환율 요인 -48만원) → 가산금리 3.00으로 변경 → 자료·해석 안내 탭의 강건성 점검 요약(BH 보정 포함).
- **발표 때와 다른 점**: 15분 발표에서는 질문용으로 넘겼던 16쪽(산점도 읽는 법)과 17쪽(다시 확인, 다중비교 보정)을 영상에는 넣었습니다. 그래서 발표 시간(15분)보다 1분쯤 깁니다.
- **만든 방법**: 내레이션은 발표대본 v5를 음성용으로 다듬어 Microsoft Edge 신경망 TTS(`edge-tts`, 발표 `ko-KR-InJoonNeural`, 시연 `ko-KR-SunHiNeural`)로 읽었습니다. 슬라이드는 발표자료 v13을 이미지로 내보냈고, 시연은 이 ZIP의 앱을 `streamlit run app/app.py`로 실행해 실제로 조작한 화면을 녹화했습니다. 화면 속 숫자는 모두 `metrics.json`·`robustness.json`과 같습니다.

## 11. API 명세서 (`API_명세서_v1.md`)

이 프로젝트는 **API 키 없이** 돌아갑니다. 원본은 `data/raw/`에 들어 있고, FRED는 원본이 없을 때만 부릅니다.

| 장 | 내용 |
| --- | --- |
| 1~3. FRED | 그래프 CSV(`fredgraph.csv`, 키 없음) 요청 파라미터·응답 형식·시계열 5개, 예비 경로 FRED API(`series/observations`, 키 선택), 시간초과·결측·응답 검사 처리 |
| 4. `analysis_core` | `read_fred_csv` → `merge_daily` → `month_end_points` → `build_monthly` → `compute_metrics` 입력·출력과 계산식 |
| 5. 앱 | `run_analysis`(전체 계산 후 자르기), `corr_test`(p값·피셔 z 신뢰구간), 사이드바 입력 범위 |
| 6. `robustness_check` | 순열검정, 블록 부트스트랩, HAC 회귀, Chow 검정, 분해 민감도, `run_all` |
| 7. 결과 파일 | `monthly_analysis.csv` 열, `metrics.json`·`robustness.json` 키 구조 |

- FRED API 키는 선택이며 제출본에는 넣지 않았습니다(노트북 `FRED_API_KEY = ""`). 키를 넣어 썼다면 공유 전에 반드시 비웁니다.
